# ARGOS 디자인 시스템

**ARGOS** — *항공 노선 및 지상 운항 관제 시스템 (Airline Route & Ground Operations System)*

인천 허브 항공사(대한항공 모델)를 위한 AI 기반 운항통제센터(OCC) 의사결정 지원 도구입니다. 포트폴리오 프로젝트로 Python 3.12, Streamlit UI, LangGraph 멀티 에이전트 백엔드, OR-Tools 최적화, LightGBM 예측을 기반으로 합니다.

> 지연 감지 → 전파 시뮬레이션 → 회복 시나리오 3개 자동 생성 → OCC 관리자 최종 승인

이 디자인 시스템은 ARGOS의 시각적 정체성을 정의합니다. 항공사 운항통제센터 특유의 차분하고 기술적인 한국어/영어 이중 언어 스타일과, OCC 사용자 흐름도에서 도출한 라벤더 + 잉크 블랙 조합을 사용합니다.

## 제품 맥락

ARGOS는 항공사의 핵심 OCC 워크플로우를 구현합니다.

1. **대시보드** — 전 기재 KPI, 출발 스케줄, 노선 지도
2. **지연 예측** — LightGBM 기반 `P(지연 ≥ 15분)` 계산
3. **전파 시뮬레이션** — 항공기 로테이션의 NetworkX DAG
4. **회복 시나리오** — 흡수 / 기재 교환 / 결항 옵션 자동 생성
5. **UAM / ACROSS** — 한국 UTM을 통한 eVTOL 대체 경로

**안전 원칙은 변경 불가입니다.** FAR 117 승무원 근무 한도는 하드 컨스트레인트이며, 모든 회복 조치는 반드시 인간의 명시적 승인이 있어야 실행됩니다 (LangGraph `human_gate` 인터럽트).

현재 라이브 UI는 OCC 대시보드(`src/argos/ui/dashboard.py`) 하나입니다. Streamlit 기반이며 운항 관제, UAM/ACROSS 두 개 탭으로 구성되어 있습니다. 나머지는 모두 서비스 레이어 Python입니다.

## 콘텐츠 원칙

ARGOS는 소비자용 SaaS 마케팅이 아닌 **항공사 운항 매뉴얼** 문체를 따릅니다.

- **이중 언어, 한국어 중심.** 사용자 향 카테고리는 한국어(`날짜 선택`, `항공편 필터링`, `회복 시나리오`), 모듈명·코드·ICAO/IATA 식별자·제품명(ARGOS, OCC, UAM, ACROSS, FAR 117)은 영어로 표기합니다.
- **간결하고 선언적.** 짧은 문장, 능동태를 씁니다. 코드베이스는 체크리스트처럼 읽혀야 합니다.
- **숫자는 항상 명확하게.** `161,868건`, `60개 노선`, `58대`. 단위는 항상 함께 표기합니다(`분`, `NM`, `ft AGL`, `편`, `명`).
- **1·2인칭 없음.** "우리", "당신" 사용 금지. 주어는 시스템 또는 항공편입니다.
- **UI에 이모지 없음.** 허용 문자는 `✈`와 화살표 글리프(`→`, `▶`)뿐이며 이마저도 절제합니다.
- **액션 버튼은 간결하게.** `날짜 선택`, `승인`, `거부/중단`, `시뮬레이션 실행`. 동사 + 명사, 한글 8자 이내 또는 영어 2단어 이내입니다.
- **안전 관련 문구는 명시적으로.** 위험 부담이 높은 상황에서는 경고를 분명히 표시합니다. *"회복 조치는 반드시 인간의 명시적 승인 후에만 실행됩니다."*

**대소문자 규칙.** 헤더와 레이블은 문장형 대소문자. 전체 대문자는 코드 전용(`ICN`, `RKSI`, `KST`, `KE001`, `HL7xxx`). 소제목 마이크로 레이블은 대문자 + 0.08em 자간.

**코드 형태의 값은 항상 고정폭**으로 표기합니다. 편명, 기체 등록번호, IATA 지연 코드, UTC 타임스탬프, 거리가 해당됩니다.

## 비주얼 기초

### 색상

팔레트는 **라벤더 + 잉크 블랙, 흰색 배경**입니다. OCC 사용자 흐름도에서 직접 도출했습니다.

- 주요 브랜드 컬러: `--argos-violet-500` (`#8B5CF6`)
- 다크 CTA 컬러: `--argos-ink-900` (`#16161D`)

운항 상태 색상이 상위 레이어로 적용됩니다.

| 토큰 | 의미 |
|---|---|
| `--status-ontime` | 정시 (초록) |
| `--status-delay` | 지연 (주황) |
| `--status-critical` | 심각 (빨강) |
| `--status-info` | 정보 (하늘) |

5개 모듈 액센트(`--module-prediction`, `--module-sim`, `--module-recovery`, `--module-uam`, `--module-dashboard`)는 OCC 워크플로우 5단계를 상태 색상과 겹치지 않게 구분합니다.

### 타이포그래피

| 폰트 | 용도 |
|---|---|
| **Noto Sans** (가변, 굵기 100–900) | UI, 본문, 헤딩 — 한글 + 라틴 이중 언어 |
| **JetBrains Mono** (CDN) | 편명, 코드, 타임스탬프, KPI 숫자, 표 형식 데이터 |

크기 스케일: `40 / 28 / 22 / 18 / 15 / 14 / 13 / 12 / 11px`
본문 **14px**, 테이블 **13px**, KPI 숫자 **40px**.
헤딩 자간 `-0.02em`, 소제목 마이크로 레이블 `+0.08em`.

### 간격 및 레이아웃

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64px` 스케일을 사용합니다.

대시보드는 **2~3단 그리드**(지도 / 스케줄 / KPI) → 전체 너비 시뮬레이션 패널 → 차트 스트립 구조입니다. 항상 좌측 사이드바(필터)와 상단 탭 바(모듈 전환)가 존재합니다.

### 테두리, 반경, 서피스

- 카드·패널: `--radius-lg` (12px), 1px 테두리, 흰색 서피스
- 버튼: 흐름도 OCC 액션 스타일의 필 형태(`--radius-pill`) 또는 `--radius-md`
- 입력 필드: `--radius-md`, 포커스 시 1.5px 테두리

### 배경

주로 평평한 흰색(`--bg-1`). 보라색 틴트(`--bg-tint`)는 하이라이트, 사이드바 헤더, 빈 상태에만 사용합니다. **그라디언트는 사용하지 않습니다.** 색상이 필요하면 단일 보라색 워시만 허용합니다.

### 이미지

데이터 시각화 중심입니다. Plotly 차트, 지오 라인 트레이스, 히스토그램, OpenStreetMap 위 NetworkX 그래프. 실제 사진이 필요하다면 무채색 항공 촬영(활주로, 터미널 내부, 하늘)만 허용합니다.

### 애니메이션

모션은 기능적으로만 씁니다.

| 토큰 | 시간 | 용도 |
|---|---|---|
| `--dur-fast` | 140ms | 호버 |
| `--dur-base` | 200ms | 메뉴·탭 전환 |
| `--dur-slow` | 320ms | 패널 표시 |

이징: `cubic-bezier(0.2, 0, 0, 1)`. 바운스, 스프링, 축하 애니메이션은 사용하지 않습니다.

### 그림자

| 토큰 | 용도 |
|---|---|
| `--shadow-1` | 정적 카드 |
| `--shadow-2` | 부각 요소 |
| `--shadow-3` | 모달 / 시나리오 카드 |

### 투명도

대부분 사용을 피합니다. 허용 범위는 상태 색상 배경, 포커스 링(`rgba(139,92,246,0.35)`), 그림자뿐입니다. 글래스모피즘과 `backdrop-filter`는 사용하지 않습니다. 운항 대시보드는 선명한 가독성이 필수입니다.

### 고정 요소

- **사이드바**: 항상 존재, 너비 약 280px, 흰색 서피스, 헤어라인 테두리
- **탭 바**: 메인 컬럼 상단, `--argos-violet-500` 언더라인 인디케이터
- **푸터 힌트**: 사이드바 하단 `--fg-3` 색상 (예: `DB: 161,868편 로드됨`)

## 아이코노그래피

현재 코드베이스에는 별도 아이콘 세트가 없습니다. Streamlit 대시보드는 유니코드 글리프(`✈ ▶ → ✅ ❌`)만 사용합니다.

이 디자인 시스템은 **[Lucide Icons](https://lucide.dev)**(CDN)을 표준 아이콘 세트로 사용합니다. 동일한 획 굵기(1.5px), 아웃라인 스타일로 차분한 기술적 톤에 잘 맞습니다.

규칙:
- **획 1.5px 아웃라인만** 사용합니다. 솔리드·듀오톤 변형은 금지입니다.
- **크기 기준**: 14px(본문 인라인), 16px(폼·테이블), 20px(사이드바 내비), 24px(KPI 모듈)
- **색상**: 기본 `--fg-2`, 호버 `--fg-1`, 활성 `--argos-violet-500`, 상태 아이콘은 해당 상태 토큰 색상

**로고 / 워드마크.** 확정된 시각 로고는 없습니다. 워드마크는 Noto Sans 700, `-0.02em` 자간의 타이포그래피 락업과 바이올렛 비행기 글리프 파비콘으로 구성됩니다.

## 알려진 사항

1. **아이콘 세트**: 코드베이스에 네이티브 아이콘이 없어 Lucide를 CDN으로 사용합니다.
2. **모노 폰트**: JetBrains Mono는 Google Fonts CDN에서 가져옵니다.
3. **로고**: 확정된 브랜드 마크가 없으며 타이포그래피 기반 워드마크를 사용합니다.
4. **단일 UI 서피스**: 현재 라이브 UI는 Streamlit OCC 대시보드 하나입니다. 모바일 앱, 마케팅 페이지 등은 존재하지 않습니다.
